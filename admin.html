🚀 Как опубликовать обновления на Vercel

  1. Нажмите кнопку «Скачать data.json» выше.
  2. Поместите скачанный файл в папку assets/data.json проекта.
  3. Запустите в терминале python build.py и git push. Проект автоматически обновится на Vercel!
